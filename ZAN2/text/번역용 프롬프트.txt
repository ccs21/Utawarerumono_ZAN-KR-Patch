# 공통사항
각 줄은 1:1로 줄 수 정확히 맞아야 하고, ""로 쌓여있는 대사(하나의 셀에 여러줄이 있는 대사)는 그대로 유지.
""로 쌓여있지 않은 한줄짜리 대사도 전부 ""로 묶어줘. 결과는 번역된 한국어만. 

거듭 강조하지만 원문과 줄 수가 1:1로 맞아야 돼. 

\n 사용 금지. 멀티라인 셀의 경우 ""로 묶여 있으니까 실제로 줄 바꿔 두어도 한개 셀에 맞춰 들어가게 되어 있잖아?
그러니까 \n은 사용하지 말고 실제 줄바꿈으로 처리 해 줘. \n은 게임에서 인식을 못하고 실제로 화면상에 \n을 띄워버리기 때문에 사용하면 안돼.

<한자:후리가나> 루비 코드는 삭제해도 게임에 문제가 없어. 루비 코드는 삭제하고, 가나쪽 기준으로 번역 하자.

# 대사번역의 경우

존댓말/반말은 일본어 문법에 맞춰서 자연스럽게 해 주고, 대사 앞이나 뒤에 알수 없는 코드 들은 절대 바꾸면 안돼. 
○○ちゃん 은 ○○쨩 으로 번역 하자.
○○やん은 ○○냥 으로 번역 하자.
○○殿는 ○○공 으로
旦那는 나리 라고 번역 하자.
칸사이벤은 경상도 사투리로 번역하되, 과한 사투리는 피하고, ○○はんっ 은 ○○씨 로 하자.

이외의 호칭은 그대로 번역 하는데, 네 마음대로 호칭을 바꿔선 안돼.
예를들어 ○○さん 이면 ○○씨 라고 해야지 ○○쨩 이라고 하면 안된다는거야.

원문에 화자명이 없어도 `でおじゃる` 계열, `にょほほ` 같은 웃음, 익살스럽지만 품위 있는 고풍 말투가 보이면 해당 대사는 자연스러운 한국어 고어체(`~이오 / ~하오 / ~구려 / ~겠구려 / ~바라오`)로 번역할 것.
이 말투는 기계적으로 직역하지 말고, `좋겠소자루요` 같은 어색한 혼합형은 절대 금지하며, 현대적인 평어/존댓말로 평범하게 풀지 말 것.
익살스러움은 살리되 개그톤으로 무너지지 않게, 품위와 약한 비극성이 함께 느껴지도록 번역할 것.


# 아이템/스킬 설명의 경우

내가 영어원문도 같이 올려 줄 거야.
이 때, 일본어 원문과 영어 원문을 비교 해 보면, 영어원문에도 일본어로 들어간 부분이 있을거야.
이게 대부분 뭔가 아이콘을 표시하는 토큰 인거같거든?
그러니까 번역은 일본어 기준으로 하되, 영어원문을 참고 삼아서, 일본어로 유지 해야 하는 토큰은 그대로 유지한 결과를 출력 해 줘야 해.
